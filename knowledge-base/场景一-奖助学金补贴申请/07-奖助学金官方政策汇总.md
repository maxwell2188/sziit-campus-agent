# 奖助学金官方政策汇总（官网最新版）

> **官方来源**：深圳信息职业技术大学学生处制度专栏
> **来源URL**：https://zd.sziit.edu.cn/info/1031/1095.htm 等
> **更新时间**：2025年（学校升格为职业技术大学后）
> **重要说明**：2024年10月国家上调奖助学金标准（财教〔2024〕181号），以下金额为新旧标准对照

---

## 一、国家奖学金（最高荣誉）

| 项目 | 官方规定 |
|------|----------|
| 奖励金额 | 旧标准8000元/年；**2024年新标准10000元/年** |
| 奖励对象 | 二年级以上（含二年级）全日制在校生中特别优秀的学生 |
| 评选比例 | 差额评审，名额极少（计软学院2025年约4名） |
| 申请条件 | 1. 无违纪记录<br>2. 学年综合测评总成绩**90分以上**（原始加权平均分，不含证书分和干部分）<br>3. 社会实践、创新能力、综合素质突出 |
| 评分标准 | 学习成绩70分 + 德育服务15分 + 素质拓展获奖15分 + 竞评演讲10分 |
| 评审时间 | 每年9月启动，9月30日前完成校内公示 |
| 互斥规则 | 获得国奖可同时获国家助学金，**但不可同时获得国家励志奖学金和学业奖学金** |
| 所需材料 | 国家奖学金申请审批表、成绩单、获奖证书、竞评PPT |

---

## 二、国家励志奖学金

| 项目 | 官方规定 |
|------|----------|
| 奖励金额 | 旧标准5000元/年；**2024年新标准6000元/年** |
| 奖励对象 | 二年级以上品学兼优的家庭经济困难学生 |
| 前提条件 | **必须通过家庭经济困难认定**（在贫困库中） |
| 成绩要求 | 成绩排名与综合测评排名均位于专业前25% |
| 互斥规则 | 同一学年不可与国家奖学金兼得，可同时获国家助学金 |
| 公示要求 | 学院公示不少于5个工作日，学校公示不少于5个工作日 |

---

## 三、国家助学金

| 项目 | 官方规定 |
|------|----------|
| 资助金额 | 旧标准平均3300元/年；**2024年新标准平均3700元/年**，分2-3档（2500-5000元） |
| 资助对象 | 家庭经济困难的全日制在校学生 |
| 前提条件 | 必须通过家庭经济困难认定 |
| 发放方式 | 分学期发放（每学期约1500元） |
| 重点保障 | 原建档立卡、低保、特困供养、孤儿、烈士子女、残疾学生等优先较高档次 |
| 互斥规则 | 可与国奖或国励同时获得 |

---

## 四、学业奖学金（校级）

| 等级 | 金额（元/学年） | 成绩要求 | 备注 |
|------|----------------|----------|------|
| 特等奖 | 12000 | 绩点4.25以上（加权92.5分） | 全校仅10名，需PPT竞评 |
| 一等奖 | 4000 | 加权平均≥90分（绩点4.0） | 综合测评优秀 |
| 二等奖 | 2500 | 加权平均≥80分（绩点3.0） | 综合测评优良 |
| 三等奖 | 1500 | 加权平均≥75分（绩点2.5） | 综合测评优良 |

### 成绩计算官方规则
```
加权平均分 = ∑（课程成绩 × 课程学分） / ∑总学分
```
- 计算范围：所有必修课和专业选修课
- 职业资格证书加分：初级+0.2分，中级+0.5分，高级+1分（毕业必备证书不加分）
- 优秀学生干部/团干部加0.5分（不重复加）
- 五级制换算：优秀=95分，良好=85分，中等=75分，及格=65分，不及格=55分
- **重要：各级别学业奖学金不可兼得**

## 五、其他校内奖助项目

### 1. 新生奖学金
| 等级 | 金额 | 条件 |
|------|------|------|
| 一等奖 | 10000元 | 高考分数超过本科线，总分排前三名 |
| 二等奖 | 5000元 | 高考分数超过本科线（不含前三名） |
| 三等奖 | 3000元 | 深圳户籍考生，录取人数前10% |

### 2. 考证奖学金
| 证书类型 | 奖励金额 |
|----------|----------|
| 高级职业资格证书 | 500元/证 |
| 行业顶尖证书（HCIE/CCIE/OCM等） | 最高15000元 |
| CET-4（大学英语四级） | 200元 |
| CET-6（大学英语六级） | 500元（非英语专业）/200元（英语专业） |

### 3. 竞赛获奖奖学金
| 级别 | 一等奖 | 二等奖 | 三等奖 |
|------|--------|--------|--------|
| 国家级 | 5000元 | 4000元 | 3000元 |
| 省部级 | 3000元 | 2000元 | 1000元 |
| 市级 | 2000元 | 1200元 | 800元 |

### 4. 深信年度人物
- 金额：4000元/人，每年10名
- 评选：学习竞赛、自强、创业、志愿、服务、见义勇为、孝老爱亲等方面突出者

### 5. 勤工助学
- 固定岗位：约26.75元/小时
- 临时岗位：约20.3元/小时
- 工作时长：每周不超过8小时，每月不超过40小时

### 6. 国家助学贷款
- 2024年起本专科生最高额度提高至**20000元/年**
- 在校期间利息由国家财政全额补贴

## 六、通用申请材料清单

申请所有奖助学金通用材料：
1. 对应奖助学金申请（审批）表
2. 成绩单（教务系统打印）
3. 获奖证书、职业资格证书原件及复印件
4. 家庭经济困难证明（助学金/励志奖学金需要，含《家庭经济困难调查表》）
5. 学生干部任职证明、社会实践/公益活动证明
6. 个人事迹材料（国家奖学金、特等奖学金需要PPT竞评）

---

## 七、通用注意事项

1. 所有评审坚持**公开、公平、公正**，公示期内可提出异议
2. **严禁弄虚作假**，一经查实取消资格并追回奖金
3. 受纪律处分者、有抽烟酗酒铺张浪费行为者取消参评资格
4. 资助资金不得用于高消费或奢侈消费
5. 每年具体时间节点以学生处当年9月发布的评选通知为准
