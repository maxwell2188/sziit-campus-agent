## 一、国家奖学金申请审批表

### 表格用途

用于国家奖学金申请，是学生申报国家奖学金的核心表格。学院拟推荐4名，奖励标准10000元/人·年。

### 字段说明

| 字段名称 | 填写规范 |
|-----------|----------|
| 基本信息 | 姓名、学号、年级、专业、班级等，须与学籍信息一致 |
| 学业成绩 | 填写学习成绩加权平均分及专业排名 |
| 综合表现 | 简述思想品德、学业成绩、科研创新、社会实践等方面表现 |
| 获奖情况 | 列举主要获奖情况，注意加分项不可累加只可取最高分项 |
| 申请理由 | 简明扼要阐述申请理由 |
| 演讲PPT | 需单独准备，时长2分30秒 |

### 盖章要求

- 学生本人签名
- 班主任意见及签名
- 辅导员意见及签名
- 学院意见及盖章

### 提交格式

- 纸质版本签名盖章后提交
- 配套演讲PPT电子版
- 截止时间：9月12日17:00前

## 二、国家助学金申请表

### 表格用途

用于国家助学金申请，是所有年级学生申请助学金的必填表格。全院名额211个。

### 字段说明

| 字段名称 | 填写规范 |
|-----------|----------|
| 基本信息 | 姓名、学号、年级、专业、班级等，须与学籍信息一致 |
| 家庭经济情况 | 如实填写家庭经济状况，须与困难认定结果一致 |
| 困难等级 | 填写已认定的困难等级（特别困难/比较困难/一般困难） |
| 学业表现 | 填写学习态度及成绩情况 |
| 申请理由 | 简明扼要阐述申请助学金的理由 |

### 盖章要求

- 学生本人签名
- 班主任意见及签名
- 辅导员意见及签名
- 学院意见及盖章

### 提交格式

- 25级学生：填写申请表 + 汇总表
- 23/24级学生：填写申请表 + 汇总表 + 评分表 + 佐证材料 + 班级公示材料
- 截止时间：10月24日前

## 三、综合测评汇总表（表1）

### 表格用途

用于各班级汇总学生综合测评成绩，是奖学金评选的核心数据表格。

### 字段说明

| 字段名称 | 填写规范 |
|-----------|----------|
| 学生信息 | 姓名、学号、专业、班级 |
| 基础分 | 学习学业分，按专业排名计算（1%-5%为60分，每后5%减1分） |
| 素质拓展分 | 包含德育实践、知行合一等加分项，上限40分 |
| 总分 | 基础分 + 素质拓展分，上限100分 |
| 专业排名 | 根据总分在专业内排序 |

### 填写规范

- 基础分按学习成绩专业排名百分比换算：排名前1%-5%得60分，每后退5%减1分
- 素质拓展分各子项不得超过各自上限，总分不得超过100分
- 同分情况下按学习成绩加权平均分高者优先

### 盖章要求

- 综测小组长签名
- 班主任审核签名
- 辅导员确认签名

### 提交格式

- 电子版Excel格式提交
- 配合加分项佐证材料一并提交

## 四、综合测评汇总表（表2）

### 表格用途

用于年级层面汇总各班级综合测评结果，用于年级审议环节。

### 字段说明

| 字段名称 | 填写规范 |
|-----------|----------|
| 班级 | 填写具体班级名称 |
| 学生信息 | 姓名、学号、专业 |
| 各项得分 | 基础分、素质拓展分、减分项、总分 |
| 年级排名 | 年级内排序结果 |
| 审议意见 | 年级审议小组填写审议结果 |

### 填写规范

- 各班交换审议，确保公平公正
- 审议意见需明确写出“同意”或“不同意”及理由
- 年级公示不少于1天

### 盖章要求

- 年级审议小组成员签名
- 辅导员确认签名

### 提交格式

- 电子版Excel格式提交
- 随班级汇总表一并提交

## 五、助学金评分表

### 表格用途

专用于23/24级学生国家助学金评分，与综合测评汇总表不同，本表重点在自强不息、困难等级等助学金专属指标。

### 字段说明

| 字段名称 | 填写规范 |
|-----------|----------|
| 学生信息 | 姓名、学号、专业、班级、年级 |
| 困难等级 | 特别困难/比较困难/一般困难，须与认定结果一致 |
| 自强不息得分 | 学习成绩排名得分（最高30分）+ 困难等级得分（特别困难30/比较困难15/一般困难10） |
| 其他加分项 | 德育实践、知行合一等加分 |
| 减分项 | 三比-1分/次，旷课-2分/节，挂科-2分/门 |
| 总分 | 加分项合计 - 减分项合计 |

### 填写规范

- 困难等级得分标准：特别困难30分、比较困难15分、一般困难10分
- 学习成绩排名得分最高30分
- 减分规则：三比每次扣1分（≥3次取消资格），旷课每节扣2分（≥10节取消资格），挂科每门扣2分（≥3门取消资格）
- 同分情况下按困难等级优先

### 盖章要求

- 学生本人确认签名
- 综测小组长签名
- 班主任审核签名

### 提交格式

- 电子版Excel格式
- 仅限23/24级学生填写，25级不需填写
- 配合佐证材料一并提交

## 六、助学金初审名单汇总表

### 表格用途

用于汇总全院助学金初审通过的学生名单，作为学院公示及上报的依据。

### 字段说明

| 字段名称 | 填写规范 |
|-----------|----------|
| 学生信息 | 姓名、学号、专业、班级、年级 |
| 困难等级 | 特别困难/比较困难/一般困难 |
| 助学金评分 | 填写评分表中的最终得分 |
| 建议分档 | 一档（4200元/年）或二档（3200元/年），高年级按成绩分档 |
| 初审意见 | 班级/年级初审结果 |

### 填写规范

- 25级全覆盖96名，均为3700元/年
- 23级名额73名，24级名额42名，按困难生人数比例分配
- 高年级（23/24级）按成绩分为一档和二档
- 名额分配须严格按照学院下达的名额分配表执行

### 盖章要求

- 辅导员审核签名
- 学院负责人签名盖章

### 提交格式

- 电子版Excel格式
- 配合班级公示材料一并提交
- 截止时间：10月24日前
