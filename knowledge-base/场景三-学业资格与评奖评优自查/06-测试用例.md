## 测试用例列表

### 用例1：模糊提问 - "我能拿奖学金吗"
**问题**：我能不能拿奖学金啊？
**类型**：模糊提问
**预期命中文档**：
- 01-办事规则总览.md → 学业奖学金评定标准
- 03-FAQ问答库.md → 学业奖学金类
- 04-避坑指南.md → 奖学金基本条件

**预期回答要点**：
- 反问澄清：想了解哪类奖学金？目前绩点大概多少？有没有挂科？
- 说明学业奖学金有4个等级，各有绩点要求
- 说明申请奖学金还有其他基本条件（无挂科、参加公共服务、体测合格、无违纪等）
- 引导用户提供更多信息以便准确判断

### 用例2：复杂提问 - "绩点3.6排名15%无挂科有志愿证书能拿几等奖"
**问题**：我大二，绩点3.6，专业排名15%，没有挂科，有志愿服务证书，还参加了学科竞赛拿了三等奖，能拿几等奖学金？
**类型**：复杂提问（多条件综合判断）
**预期命中文档**：
- 01-办事规则总览.md → 学业奖学金评定标准 + 综合测评体系
- 02-表格模板库.md → 综测汇总表
- 03-FAQ问答库.md → 综测加分类

**预期回答要点**：
- 绩点3.6对应加权平均分86分左右，符合二等奖学金（≥80分/绩点≥3.0）的成绩要求
- 排名15%基础分大概57-58分左右
- 志愿服务和竞赛获奖可以加素质拓展分，具体加分看证书级别
- 综合来看二等奖学金比较有希望，一等奖需要看综测总排名
- 提醒注意其他基本条件（公共服务、体测、无违纪等）

### 用例3：错误提问 - "挂了一科补考及格了还能评奖学金吗"
**问题**：我上学期挂了一科，但是补考已经过了，今年还能评奖学金吗？
**类型**：错误提问（对规则理解有误）
**预期命中文档**：
- 01-办事规则总览.md → 申请奖学金基本要求
- 03-FAQ问答库.md → 挂科了还能评吗
- 04-避坑指南.md → 挂科还想评奖学金

**预期回答要点**：
- 明确回答：不能
- 解释原因：申请奖学金要求"评选年度内无不及格科目"，挂过科即使补考通过也不行
- 可以关注国家助学金（助学金允许有挂科，但挂科≥3门也取消资格）
- 提醒以后注意，下一年度如果没有挂科就可以参评了

### 用例4：边界情况 - "旷课刚好10节能不能评"
**问题**：我这学期旷课累计10节，还能评奖学金吗？
**类型**：边界情况（资格边界）
**预期命中文档**：
- 01-办事规则总览.md → 综测减分规则
- 02-表格模板库.md → 综测汇总表减分项
- 04-避坑指南.md → 旷课扣分

**预期回答要点**：
- 明确回答：不能
- 说明规则：旷课-2分/节，累计旷课10节及以上直接取消评选资格
- 你刚好10节，已经达到取消资格的标准
- 提醒以后注意考勤，遵守纪律是基本要求

### 用例5：模糊提问 - "我能不能毕业"
**问题**：我这样能正常毕业吗？
**类型**：模糊提问
**预期命中文档**：
- 01-办事规则总览.md → 毕业资格硬性要求
- 03-FAQ问答库.md → 毕业资格类
- 04-避坑指南.md → 学分不足、体测、处分等

**预期回答要点**：

### 用例6：复杂提问 - "助学金和奖学金能同时拿吗"
**问题**：我是困难生，成绩还不错，助学金和奖学金能同时申请吗？能都拿到吗？
**类型**：复杂提问（兼得规则）
**预期命中文档**：
- 01-办事规则总览.md → 奖助学金兼得规则
- 03-FAQ问答库.md → 兼得规则类
- 04-避坑指南.md → 兼得规则搞错

**预期回答要点**：
- 国家励志奖学金与国家奖学金、学业奖学金不可兼得
- 国家助学金和学业奖学金，在符合各自条件的情况下可以同时获得
- 但国家助学金需要家庭经济困难认定，学业奖学金需要成绩达标
- 建议可以同时申请，最终看评选结果
- 具体以当年政策为准，拿不准可以问辅导员

### 用例7：错误提问 - "综测分满分100，我要刷到100分"
**问题**：综测总分是100分对吧？我要把所有能加的分都加上，争取拿满分！
**类型**：错误提问（对综测规则理解有误）
**预期命中文档**：
- 01-办事规则总览.md → 综合测评体系
- 03-FAQ问答库.md → 综测分越多越好吗
- 04-避坑指南.md → 综测分误区

**预期回答要点**：
- 纠正理解：综测总分上限确实是100分，但不是有多少加多少
- 各分项有上限：德育实践最高22分，知行合一最高18分
- 同一类别内一般只取最高项，不是累加
- 而且奖学金看的是排名不是绝对分数，关键是你在专业里排第几
- 建议重点关注学习成绩（基础分60分），素质拓展适度参与就好

### 用例8：边界情况 - "大一新生能评国奖吗"
**问题**：我是大一新生，成绩挺好的，能评国家奖学金吗？
**类型**：边界情况（年级边界）
**预期命中文档**：
- 01-办事规则总览.md → 奖助学金申请条件
- 03-FAQ问答库.md → 大一新生能评吗
- 05-时间节点表.md → 国家奖学金

**预期回答要点**：
- 国家励志奖学金明确要求二年级及以上年级
- 国家奖学金一般也是大二及以上参评
- 大一新生可以关注校内其他奖学金项目
- 先好好学习打好基础，明年机会更大
- 具体以当年评选通知为准

### 用例9：复杂提问 - "体测不合格影响奖学金和毕业吗"
**问题**：体测没过怎么办？会影响奖学金吗？影响毕业吗？
**类型**：复杂提问（多维度影响）
**预期命中文档**：
- 01-办事规则总览.md → 毕业资格 + 奖学金基本要求
- 03-FAQ问答库.md → 体测不合格影响
- 04-避坑指南.md → 体测忘了去

**预期回答要点**：
- 体测合格既是奖学金申请的基本条件，也是毕业的硬性要求
- 申请奖学金需要体质健康测试合格（因病/残疾经核准免测除外）
- 毕业也需要《国家学生体质健康标准》测试成绩合格
- 不合格可以申请补测，争取补测通过
- 平时多锻炼，体测不难通过的

---

### 用例10：模糊提问 - "有什么办法可以加分"
**问题**：综测怎么加分比较快？有什么容易拿分的项目？
**类型**：模糊提问（加分咨询）
**预期命中文档**：
- 01-办事规则总览.md → 综合测评加分标准
- 02-表格模板库.md → 综测汇总表
- 03-FAQ问答库.md → 综测加分类

**预期回答要点**：
- 说明综测加分的两大板块：德育实践（最高22分）和知行合一（最高18分）
- 德育实践方面：志愿服务、公共服务、担任学生干部、三下乡等都可以加分
- 知行合一方面：考专业技能证书、参加学科竞赛、体育比赛获奖等
- 提醒：学习成绩才是基础（占60分），加分是锦上添花，别本末倒置
- 建议结合自己的兴趣和特长选择，别为了加分盲目参与
- 所有加分都需要有盖章的证明材料，志愿时长以"志愿深圳"系统为准
