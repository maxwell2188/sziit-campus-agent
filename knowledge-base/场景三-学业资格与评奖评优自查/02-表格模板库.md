# 学业资格与评奖评优自查 - 表格模板库

> **官方来源**：深圳信息职业技术大学计算机与软件学院奖助学金评选实施细则（2026年修订）
> **发布时间**：2026年3月
> **同义词映射**：综测表 = 综合测评表 = 加分表 = 评分表；申请表 = 审批表 = 申请单

---

## 一、奖学金综合测评汇总表1（适用于国家励志奖学金、学业奖学金特等奖）

### 1.1 适用范围
- 国家励志奖学金申请
- 学业奖学金特等奖申请

### 1.2 填写要求
- **申请基本要求**（需同时满足）：
  - 无旷课记录
  - 无挂科记录
  - 无违反公寓"安全三比"记录
- 加分需提交带有主办方或学校、学院印章的证明材料

### 1.3 表格构成
- **基础分-学习学业（60分）**：按专业排名换算
- **素质拓展分（40分）**：
  - 德育实践（最高22分）：追求卓越、无私奉献、劳动素养、身体素质
  - 知行合一（最高18分）：技能竞赛、体育赛事、语言素养
- **减分项**：三比-1分/次、旷课-2分/节（累计10节及以上取消资格）

### 1.4 提交要求
- 纸质版及佐证材料提交至班级综测小组
- 在规定截止时间前提交，逾期不受理
- 所有加分项需提供证书、奖状等佐证材料原件或复印件

> 来源：深圳信息职业技术大学计算机与软件学院奖助学金评选实施细则（2026年修订）附件3 表1

## 二、奖学金综合测评汇总表2（适用于学业奖学金一二三等奖）

### 2.1 适用范围
- 学业奖学金一等奖
- 学业奖学金二等奖
- 学业奖学金三等奖

### 2.2 表格构成
- **基础分-学习学业（60分）**：按专业排名换算（1%-5%为60分，每后5%减1分）
- **素质拓展分（40分）**：
  - 德育实践（最高22分）：追求卓越（最高8分）、无私奉献（最高12分：志愿5+公服4+三下乡3）、劳动素养（最高2分）、身体素质（最高1分）
  - 知行合一（最高18分）：技能竞赛（最高14分：证书6+比赛8）、体育赛事（最高7分）、语言素养（最高4分）
- **减分项**：
  - 三比违规：-1分/次
  - 旷课：-2分/节
  - 累计旷课10节及以上：取消评选资格

### 2.3 填写规范
- 每一项加分都要标注对应的加分标准条目
- 志愿时长以"志愿深圳"义工时登记数据为准
- 公共服务以"学生职业素质银行"数据为准
- 评选学年时间范围：上年9月1日至评选当年8月31日

> 来源：深圳信息职业技术大学计算机与软件学院奖助学金评选实施细则（2026年修订）附件3 表2

## 三、国家助学金综合测评汇总表

### 3.1 适用范围
- 国家助学金申请（23级、24级困难生需填写）
- 25级困难生无需填写评分表（全覆盖）

### 3.2 表格构成
- **基础分-自强不息（60分）**：
  - 学习成绩排名（最高30分）
  - 困难等级：特别困难30分 / 比较困难15分 / 一般困难10分
- **素质拓展分（40分）**：与奖学金综测表一致
- **减分项**：
  - 三比违规：-1分/次，累计≥3次取消资格
  - 旷课：-2分/节，累计≥10节取消资格
  - 挂科：-2分/门，挂科≥3门取消资格

### 3.3 同分排序
- 助学金同分情况下，按困难等级优先

> 来源：深圳信息职业技术大学计算机与软件学院奖助学金评选实施细则（2026年修订）附件4

## 四、国家奖学金申请审批表

### 4.1 基本情况字段
| 字段 | 填写规范 | 注意事项 |
|-----|---------|---------|
| 姓名 / 性别 / 出生年月 | 真实填写 | 与身份证一致 |
| 政治面貌 / 民族 / 入学时间 | 如实填写 | |
| 院系 / 专业 / 学制 | 填写全称 | 如"计算机与软件学院" |
| 年级 / 班级 / 联系电话 | 准确填写 | 联系电话保持畅通 |
| 身份证号 | 18位完整号码 | 不得有空格或符号 |

### 4.2 学习情况字段
| 字段 | 填写规范 | 注意事项 |
|-----|---------|---------|
| 成绩排名 | 名次/总人数 | 如"3/150" |
| 实行综合考评排名 | 选填"是"或"否" | |
| 必修课门数 | 填写具体门数 | |
| 及格以上门数 | 填写具体门数 | 必须全部及格 |
| 综合排名 | 名次/总人数 | 如实行综合考评则填写 |

### 4.3 主要获奖情况
- 填写格式：日期 + 奖项名称 + 颁奖单位
- 最多4行，按重要程度排序
- 需附获奖证明材料复印件

### 4.4 申请理由
- 200字左右
- 申请人签名：必须手写签名
- 日期：填写申请日期

### 4.5 填写注意事项
- 严格按照填写说明填写，否则取消评选资格
- 附件2中签名和日期无需填写（等待流程签署）
- 附件3中材料按一级指标顺序放置
- 所有加分项不可累加，只可取最高分项

> 来源：计算机与软件学院关于开展2025年国家奖学金评选工作的通知（2025年9月）

## 五、国家助学金申请表

### 5.1 本人情况
- 姓名、性别、出生年月、一寸照片
- 民族、政治面貌、入学时间、学号
- 联系电话、身份证号码
- 学院、专业、班级

### 5.2 家庭经济情况
- 家庭户口：A城镇 / B农村
- 家庭人口总数、家庭月总收入、人均月收入
- 收入来源、家庭住址

### 5.3 家庭成员情况
- 姓名、年龄、与本人关系、工作或学习单位
- 逐行填写所有家庭成员

### 5.4 学业情况
- 是否有不及格科目：A是 / B否
- 义工时数：填写具体小时数

### 5.5 申请理由与签名
- 申请理由：如实填写家庭经济困难情况
- 申请人签名：必须手写签名
- 日期：填写申请日期

### 5.6 各级意见栏
- 学生办意见：辅导员签字
- 二级学院意见：党总支书记签字（盖章）
- 学生处审核意见：签字盖章

> 来源：深圳信息职业技术学院国家助学金申请表（附件1）
