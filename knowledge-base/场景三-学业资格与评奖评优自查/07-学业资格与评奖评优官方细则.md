# 学业资格与评奖评优官方细则（官网最新版）

> **官方来源**：深圳信息职业技术大学教务处《学生学籍管理办法》（2017年修订）、学生处《各类个人、集体荣誉奖评审细则》
> **来源URL**：https://sg.sziit.edu.cn/info/1128/1350.htm、https://zd.sziit.edu.cn/info/1031/1094.htm
> **更新时间**：2025年（学校升格职业技术大学后）
> **注意**：学校2025年升格为本科层次职业大学，首届本科生2025年入学，本科具体细则以最新文件为准

## 一、学制与修业年限

| 层次 | 基准学制 | 最长在校年限（含休学） |
|------|----------|----------------------|
| 三年制专科 | 3年 | 不超过6年 |
| 二年制专科 | 2年 | 不超过5年 |
| 职业本科 | 4年 | 待官方公布 |

- 可申请提前毕业（不超过1年）或延长修业
- 学满一学年以上退学可发肄业证书或写实性学习证明

---

## 二、毕业资格规定

### 毕业条件
有正式学籍的学生，在规定年限内同时满足以下条件，准予毕业：
1. ✅ 修完专业人才培养方案规定的全部内容
2. ✅ 成绩合格，达到毕业学分要求
3. ✅ 获得专业人才培养方案规定的职业资格证书/技能证书
4. ✅ 德育总评合格
5. ✅ 无未解除的纪律处分
6. ✅ 体质测试成绩合格
7. ✅ 学籍注册正常，缴清学费

> ⚠️ 各专业具体毕业总学分要求以各专业《人才培养方案》为准（不同专业不同），学校层面无统一固定学分。

### 结业与换证
- 修完培养方案但未达毕业要求（学分不足或证书未达标）→ **结业证书**
- 结业后**3年内**可申请回校重修不及格课程，修满学分换发毕业证书
- 3年内不申请或重修仍不及格，不再受理

## 三、绩点计算官方规则（非常重要）

### 百分制绩点对应表
| 百分制成绩 | 绩点 | 五级制 | 绩点 |
|-----------|------|--------|------|
| 60分 | 1.0 | 优 | 4.5 |
| 60分以上每增加1分 | +0.1绩点 | 良 | 3.5 |
| 100分 | **5.0**（满分5.0） | 中 | 2.5 |
| 不及格（<60分） | 0 | 及格 | 1.5 |
| | | 不及格 | 0 |

### 平均学分绩点（GPA）公式
```
一门课程学分绩点 = 课程绩点 × 课程学分数
平均学分绩点（GPA）= Σ（课程绩点 × 课程学分） / Σ课程学分
```

### ⚠️ 极其重要的规定
- **补考或重修成绩合格后，课程成绩按实际成绩记入，但绩点均记为"0"**
- 平均学分绩点每学期结算一次
- 这意味着：只要挂过科（哪怕补考/重修通过），绩点会受严重影响，奖学金评选可能受影响

## 四、挂科、补考与重修规定

| 课程类型 | 补考政策 |
|---------|---------|
| 必修课 | 考核不及格，下学期安排1次补考 |
| 专业拓展课 | 不及格经审批可安排1次补考 |
| 素质拓展课 | 不及格不安排补考，不记入学业成绩，可重选/另选 |
| 缓考 | 成绩按正常考核计；缓考不及格或无故缺席需重修 |

### 重修规则
1. 每门不合格课程（不含素质拓展课）**只允许重修1次**
2. 结业生离校3年内允许重修不合格课程1次
3. 每学期重修课程一般不超过3门
4. 重修课程冲突可申请免听，但须完成作业、测验、实习后方可考试

### 取消考试资格（无法参加期末考试）
出现以下情况之一，不得参加该课程期末考核和补考，必须重修：
- 某门课程旷课学时累计超过总学时的 **1/3**
- 或缺课学时累计超过 **1/2**
- 或缺交作业量累计超过 **1/2**

## 五、留级预警与退学条件

### 应予留级（编入下一年级）
- 一学年未获学分达到或超过应修学分总数的1/3
- 跨学年累计未获学分达到15学分
- 入学以来重修后未获学分的必修和限选课累计≥5门

### 应予退学
- 编入下一年级超过2次
- 一学年所选课程未获学分数达2/3及以上
- 在校学习时间累计超过基准学制3年以上
- 休学/保留学籍期满不办复学手续
- 未请假离校连续两周未参加教学活动
- 超过规定期限未注册又无正当事由

### 考试作弊后果
- 违反考核纪律或作弊：该课程成绩记零，不准参加补考
- 组织作弊、替考等严重作弊：在校期间不能重修该课程，毕业后经申请可给予一次机会
- 其他作弊：暂缓一年后可重修一次

## 六、评奖评优官方条件

### 1. 三好学生

| 项目 | 官方规定 |
|------|----------|
| 评选比例 | 不超过在校生总数的 **5%** |
| 思想品德 | 热爱祖国，积极参加集体活动，**无违纪违规记录**，道德品质好 |
| 学习要求 | 学习态度端正，**无旷课记录**，积极参加专业活动 |
| 成绩要求 | 本学年学业成绩排名专业**前30%以内**，各考试考查科目**首次全部合格** |
| 综测要求 | 年度综合测评成绩排名专业**前20%以内** |
| 体育要求 | 积极参加体育锻炼，**体质测试成绩优良** |

### 2. 优秀学生干部

| 项目 | 官方规定 |
|------|----------|
| 评选比例 | 不超过在校生总数的 **3%**（大二、大三年级每班约1名） |
| 思想品德 | 坚持原则，办事公道，工作主动有开创精神，威信高，**无违纪** |
| 学习要求 | 学习认真，正确处理学习与工作关系，**各科目首次全部合格** |
| 成绩要求 | 学业成绩排名专业**前50%以内** |
| 体育要求 | **体质测试成绩优良** |
| 职务要求 | 担任校/院/班级学生干部满一学年 |
| 奖励 | 荣誉证书 + **奖金1000元** |
| 优先条件 | 校级学生组织主要负责人、班长、团支书等优先 |

### 3. 优秀毕业生
- 评选对象：全日制应届毕业生
- 基本门槛：无违纪记录、成绩优良、综合表现突出
- 表彰：学校发文表彰，颁发荣誉证书
- 具体条件以当年学生处通知为准

### 4. 先进班集体
- 每个奖励5000元

### 5. 文明宿舍
- 按学生宿舍数10%评选

## 七、体质测试硬性要求

### 体测与评优挂钩
- **三好学生、优秀学生干部评选明确要求"体质测试成绩优良"，为参评必要条件**

### 体测免测规定
- 因先天器质性重大疾病或残疾确实丧失运动能力的学生，可提交《免予执行〈国家学生体质健康标准〉申请》，经审批后标记"因病免测"
- 因体弱、慢性病不宜剧烈活动的，编入**保健班**学习

### 常规测试项目
| 男生 | 女生 |
|------|------|
| 肺活量、身高体重、坐位体前屈、立定跳远、50米跑、引体向上、1000米跑 | 肺活量、身高体重、坐位体前屈、立定跳远、50米跑、仰卧起坐、800米跑 |

## 八、综合测评体系

### 权重分配
| 测评维度 | 权重 | 内容 |
|----------|------|------|
| 人文道德素质 | 30% | 基础分 + 记实加分 + 记实减分 |
| 专业学习素质 | 40% | 基础分 + 记实加分 + 记实减分 |
| 身心发展素质 | 30% | 基础分 + 记实加分 + 记实减分 |

### 加分项参考
- 职业资格证书：初级+0.2，中级+0.5，高级+1分
- 学科竞赛获奖：国家级/省级/市级分别加分
- 志愿服务、社会实践、学生干部任职等
- 大学英语四级+0.2，六级+0.5分

### 减分项参考
- 旷课：-2分/节（累计10节取消评优资格）
- "三比"（比阔气、比消费、比享乐）：-1分/次
- 违纪处分：按处分等级扣分

### 测评程序
1. 学生网上自评（综合素质测评系统）
2. 辅导员+班干部他评（自评40% + 他评60%）
3. 系领导审核
4. 学生处公示3天，无异议后审批

## 九、考勤与纪律处分

### 考勤换算
- 迟到/早退累计3次 = 旷课1学时
- 教学实践环节每天按旷课4学时计

### 旷课处分阈值
| 旷课时数 | 处分 |
|---------|------|
| 10-19学时 | 警告 |
| 20-29学时 | 严重警告 |
| 30-39学时 | 记过 |
| 40-49学时 | 留校察看 |
| 50学时或连续两周以上 | 开除学籍 |

---

## 十、转专业规定

- 仅限一、二年级学生申请，在校期间只能转1次
- 申请条件：无违纪、所学课程全部合格、无恶意欠费
- 电子信息大类、制造大类专业间互转不限制名额，其他专业转出不超过班级人数10%
- 二年级学生转专业后应**降级就读**
- 特殊类型录取学生（自主招生、三二分段、五年一贯制等）不能转入统招专业
