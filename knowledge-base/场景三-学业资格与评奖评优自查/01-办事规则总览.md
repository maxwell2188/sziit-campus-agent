# 学业资格与评奖评优自查 - 办事规则总览

> **官方来源**：深圳信息职业技术学院教务处、学生处、计算机与软件学院
> **发布时间**：2026年3月（以奖助评选实施细则2026年修订版为准）
> **同义词映射**：奖学金 = 奖助学金 = 评优 = 评奖；毕业资格 = 能不能毕业 = 学分够不够；综测 = 综合测评 = 素质加分 = 加学分

---

## 一、毕业资格硬性要求

需同时满足以下全部条件，方可正常毕业：

### 1.1 学分要求
- 修完本专业人才培养方案规定的全部课程与实践环节
- 修满规定毕业总学分：
  - 普通专业总学分 ≤ 185学分
  - 艺术类专业总学分 ≤ 200学分
- 创新学分最多可抵扣4-5个选修课学分

### 1.2 德育要求
- 德育总评合格
- 无未解除的重大违纪处分

### 1.3 体质要求
- 《国家学生体质健康标准》综合测试成绩合格
- 因病或残疾经核准免测除外

### 1.4 学籍要求
- 完成每学期学籍注册
- 缴清学费
- 在校时长符合学制要求

## 二、学业奖学金评定标准

### 2.1 各等级奖学金要求

| 奖项等级 | 绩点要求 | 加权平均分 | 附加要求 |
|---------|---------|-----------|---------|
| 特等奖学金 | ≥4.25 | ≥92.5分 | 学院限额推荐，综合全面优秀；需无旷课、无挂科、无违反公寓"安全三比"记录 |
| 一等奖学金 | ≥4.0 | ≥90分 | 综合测评优秀 |
| 二等奖学金 | ≥3.0 | ≥80分 | 综合测评优良 |
| 三等奖学金 | ≥2.5 | ≥75分 | 综合测评优良 |

### 2.2 绩点与百分制换算规则
- 60分 = 1.0绩点
- 每提升1分增加0.1绩点
- 例：70分=2.0，80分=3.0，90分=4.0，95分=4.5

### 2.3 加权平均分计算方式
加权平均分 = Σ（课程成绩 × 课程学分）÷ 总课程学分

计算范围：必修课 + 专业选修课全部计入
- 考取职业资格证书可按当年规定加分
- 所有加分项不可累加，只可取最高分项（国家奖学金）

### 2.4 申请奖学金基本要求（需全部满足）
1. 遵守宪法和法律，热爱祖国，拥护党的领导
2. 遵守学校规章制度，评选学年内不得无故旷课
3. 尊师爱校，无损害学校声誉言行
4. 孝敬父母，诚实守信，遵守社会公德
5. 刻苦学习，评选年度内无不及格科目（所有课程）
6. 参加至少一次学院公共服务活动（以学生职业素质银行数据为准）
7. 体质健康测试合格（因病/残疾经核准免测除外）
8. 评奖年度未受通报批评或违纪处分

## 三、综合测评体系

### 3.1 总分构成
- 综合测评总分 = 基础分（60分）+ 素质拓展分（40分）
- 总加分上限为100分

### 3.2 基础分（60分）
**学习学业（奖学金类）**：
- 按专业排名，1%-5%为60分
- 每后5%减1分
- 最高60分

**自强不息（助学金类）**：
- 学习成绩排名（最高30分）
- 困难等级：特别困难30分 / 比较困难15分 / 一般困难10分

### 3.3 素质拓展分（40分）

**德育实践（最高22分）**：
- 追求卓越（最高8分）：荣誉称号、担任学生骨干
- 无私奉献（最高12分）：志愿服务（最高5分）+ 公共服务（最高4分）+ 三下乡（最高3分）
- 劳动素养（最高2分）：文明宿舍、劳动活动
- 身体素质（最高1分）：军训优秀学员、体测≥80分

**知行合一（最高18分）**：
- 技能竞赛（最高14分）：专业技能证书（最高6分）+ 比赛竞赛获奖（最高8分）
- 体育赛事获奖（最高7分）
- 语言素养（最高4分）

### 3.4 减分规则
**奖学金类（综测汇总表1/2）**：
- 三比违规：-1分/次
- 旷课：-2分/节
- 累计旷课10节及以上：取消评选资格

**助学金类（助学金综测汇总表）**：
- 三比违规：-1分/次，累计≥3次取消资格
- 旷课：-2分/节，累计≥10节取消资格
- 挂科：-2分/门，挂科≥3门取消资格

### 3.5 同分排序规则
- 奖学金：按学习成绩加权平均分高者优先
- 助学金：按困难等级优先

## 四、综合测评流程

1. **发布通知**：每学年秋季学期
2. **成立测评小组**：班级5名代表（班长任组长）
3. **班级测评（自评）**：班内公示不少于1天
4. **年级测评审议**：各班交换审议，年级公示不少于1天
5. **学院公示**：不少于3天
6. **复议处理**：可逐级向带班辅导员、年级综测小组、学生办提出复议

评选学年时间区间：上年9月1日至评选当年8月31日

---

## 五、主流荣誉评选基础条件

### 5.1 三好学生 / 优秀学生干部
- 品德优良，无违纪记录
- 学业成绩优良，综合测评排名靠前
- 优秀学生干部需担任学生干部职务且履职表现良好

### 5.2 优秀毕业生
- 评选比例不超过毕业班总人数5%
- 在校学业、品德、实践综合表现突出
- 无未解除违纪处分
- 全部课程考核合格

## 六、创新学分获取途径

可申请创新学分的途径：
1. 学科竞赛获奖
2. 论文发表
3. 专利授权
4. 考取职业资格证书

创新学分最多可抵扣4-5个选修课学分，具体以当年规定为准。
