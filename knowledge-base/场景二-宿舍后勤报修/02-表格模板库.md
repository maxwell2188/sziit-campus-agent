# 宿舍后勤报修 - 表格模板库

> **官方来源**：深圳信息职业技术学院后勤集团生活服务中心
> **发布时间**：校内现行管理规则（以三大场景官方流程文档为准）
> **同义词映射**：报修单 = 维修单 = 工单 = 申请单

---

## 一、线上报修工单字段说明

线上报修通过易班APP「后勤集团报修模块」填写，各字段填写规范如下：

### 1.1 基础信息字段

| 字段名称 | 是否必填 | 填写规范 | 备注 |
|---------|---------|---------|------|
| 校区 | 必填 | 选择所在校区全称 | 下拉选择，不要手动输入 |
| 楼栋 | 必填 | 选择所在宿舍楼栋号 | 如"D栋"、"东7栋"等，下拉选择 |
| 楼层 | 必填 | 选择所在楼层 | 下拉选择 |
| 房间号 | 必填 | 完整房间号 | 如"305"、"512B"等 |
| 联系电话 | 必填 | 本人常用手机号 | 确保维修期间电话畅通，师傅会电话联系 |

### 1.2 故障信息字段

| 字段名称 | 是否必填 | 填写规范 | 备注 |
|---------|---------|---------|------|
| 故障类型 | 必填 | 从下拉列表选择 | 水电类/空调家电类/家具门窗类/土建类/其他 |
| 故障详情 | 必填 | 详细描述故障现象 | 越详细越好，如"卧室吸顶灯开灯后闪烁，有时不亮" |
| 故障照片 | 选填（强烈推荐） | 清晰的故障实拍照片 | 建议上传1-3张不同角度照片，便于师傅提前判断和准备配件 |

### 1.3 工单状态说明

| 状态 | 含义 |
|-----|------|
| 待确认 | 工单已提交，等待后勤人员确认 |
| 已派单 | 已分配给对应维修师傅 |
| 维修中 | 师傅已上门处理 |
| 已完成 | 维修完成，等待学生验收 |

## 二、线下纸质报修单填写规范

线下报修在各楼栋宿管值班室填写纸质维修申请单。

### 2.1 填写要求

1. **房间号**：准确填写楼栋+房间号，如"D305"
2. **故障类型**：勾选对应类别（水电/空调/家具/其他）
3. **故障描述**：简要描述故障现象
4. **联系电话**：本人手机号
5. **报修日期**：填写当天日期
6. **报修人签名**：本人签字确认

### 2.2 提交格式

- 填写完成后交给宿管值班人员
- 宿管统一汇总后安排维修
- 维修师傅上门时会电话联系

---

## 三、报修信息准确性要求

**错误填写信息不准确会导致维修延误，请务必注意：

1. **房间号不能写错**：楼栋号+房间号必须准确，错一个数字师傅可能跑错楼
2. **联系电话要畅通**：维修师傅上门前会电话联系，无人接听不到会延后
3. **故障类型选对类别**：分类错误会派错师傅，延误维修时间
4. **故障描述尽量详细**：便于提前准备配件，一次修好
