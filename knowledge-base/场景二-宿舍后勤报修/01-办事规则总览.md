# 宿舍后勤报修服务 - 办事规则总览

> **官方来源**：深圳信息职业技术学院后勤集团生活服务中心
> **发布时间**：校内现行管理规则（以三大场景官方流程文档为准）
> **同义词映射**：报修 = 维修 = 修东西 = 师傅上门；报修 = 宿舍坏了 = 东西坏了；空调维修 = 空调不凉 = 空调不制冷

---

## 一、服务范围与报修类型

### 1.1 服务范围
宿舍内家具、水电、空调、门窗等因正常使用造成的自然损坏，提供免费维修服务。

**不属于免费维修范围的情况**：
- 人为暴力损坏
- 私自改装造成的故障
- 以上情况需按学校定价缴费后维修，具体费用以学校公示定价为准。

### 1.2 报修类型分类

| 报修类别 | 常见故障示例 |
|---------|-------------|
| 水电类 | 灯具损坏、插座断电、水龙头漏水、管道堵塞、热水器故障 |
| 空调家电类 | 空调制冷/制热异常、遥控器损坏、洗衣机故障、直饮水机故障 |
| 家具门窗类 | 床铺松动、桌椅衣柜损坏、门锁故障、玻璃破损、门窗异响 |
| 土建类 | 墙面脱皮、瓷砖脱落、卫生间漏水、屋顶渗水 |
| 其他 | 消防设施异常、公共区域设施损坏 |

## 二、办理步骤

### 2.1 线上报修（推荐）
**官方入口**：易班APP → 事务中心 → 后勤集团报修模块

操作步骤：
1. 选择「生活设施报修」
2. 填写校区、楼栋、楼层、房间号
3. 填写联系电话（确保畅通，方便维修师傅联系）
4. 选择故障类型（水电/空调/家具门窗/土建/其他）
5. 详细描述故障情况
6. 上传故障实拍照片（可选，强烈推荐上传，便于维修人员提前判断问题和准备配件）
7. 提交工单，系统自动派单
8. 线上实时查看工单进度：待确认 → 已派单 → 维修中 → 已完成
9. 维修结束后线上验收，可评价服务

### 2.2 线下报修
**官方入口**：各宿舍楼栋宿管值班室

操作步骤：
1. 前往宿舍楼栋宿管值班室
2. 填写纸质维修申请单
3. 登记房间号、故障类型、联系方式
4. 宿管统一汇总后安排维修
5. 等待维修师傅上门

## 三、官方入口

| 渠道 | 入口位置 | 适用情况 |
|-----|---------|---------|
| 线上（推荐） | 易班APP - 事务中心 - 后勤集团报修模块 | 所有常规报修，可实时跟踪进度 |
| 线下 | 宿舍楼栋宿管值班室 | 不会使用手机操作、紧急情况 |
| 紧急报修 | 后勤24小时应急维修电话 | 水管爆裂、全屋断电、门锁无法进门等紧急情况 |

---

## 四、办理时限（服务时效）

| 故障类型 | 响应时效 | 说明 |
|---------|---------|------|
| 常规故障 | 工作日24小时内上门 | 简单问题当日完成维修 |
| 配件缺失故障 | 维修人员提前告知等待周期 | 配件到货后预约上门 |
| 紧急故障 | 即时处理 | 水管爆裂、全屋断电、门锁无法进门等，可拨打24小时应急电话 |

**备注**：
- 紧急故障可直接拨打后勤24小时应急维修电话优先加急处理
- 如因配件等原因无法及时维修，维修人员会提前告知等待周期

- **紧急联系**：后勤24小时应急维修电话

## 六、报修前自助排查（重要）

报修前可先自行简易排查，约30%的简单问题可自行解决：

1. **电器类问题**：检查插座是否插好、电闸是否跳闸（电闸位置通常在进门左手边或走廊）
2. **空调问题**：检查遥控器电池是否有电、空调电源是否接通
3. **水龙头/水管问题**：检查阀门是否完全打开、是否有异物堵塞
4. **灯具问题**：检查开关是否正常、灯泡是否松动

如果排查后问题仍存在，再提交正式报修。
