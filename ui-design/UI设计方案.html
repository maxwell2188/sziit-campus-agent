🔄 快捷入口触发逻辑

  • 用户点击首页场景卡片 → 自动跳转到对话页，并自动发送对应场景的初始问候语
  • 例：点击"奖助学金"卡片 → 对话页自动发送"你好，我想咨询奖助学金相关问题"
  • 顶部场景标识同步切换为对应场景名称和图标
  • 点击后保留历史对话记录，不清除上下文
  • 从快捷入口进入的对话，在历史记录中标注场景标签

💬 多轮追问交互

✅ 推荐：选项卡片式

  • Agent追问时提供2-4个选项卡片
  • 用户点击即可，无需打字
  • 降低输入成本，提升操作效率
  • 选项按相关性排序，最可能的放前面
  • 保留"其他/以上都不是"兜底选项

⚪ 备选：纯文本追问

  • 适用于开放性问题，选项无法穷举
  • 追问语气友好自然，不生硬
  • 一次只问1-2个问题，不轰炸
  • 可配合输入框占位符提示
  • 用户回答后记住，不重复询问

📄 材料生成展示规范

  • 材料清单以结构化卡片展示，每项标注"是否必选"、"格式要求"、"盖章要求"
  • 提供官方模板下载入口，标注"官方格式"标识增强可信度
  • 支持"一键复制材料清单"功能，复制到剪贴板
  • 支持"导出为文本/PDF"，便于学生对照准备
  • 材料预检结果用✅/⚠️/❌三色标识，一目了然
  • 每项材料可展开查看详细填写说明和避坑提示

网页版（PC） PC浏览器访问时居中显示手机宽度容器，左右留白，不拉伸变形 🟡 P1
触控尺寸 所有可点击元素最小 44×44px，防止误触；按钮间距 ≥ 8px 🔴 P0
字体大小 正文不小于 14sp，辅助文字不小于 12sp，支持系统字体放大（最多+2级） 🟡 P1
深色模式 预留深色模式适配能力，MVP阶段可只做浅色模式 🟢 P2
弱网适配 网络差时显示加载状态和重试按钮，不白屏不崩溃 🟡 P1

07 赛事演示建议
突出AI价值，打动评审
  • 开场30秒：展示首页，3个场景卡片点击进去，展示入口清晰
  • 核心演示1（奖助）：点击奖助学金卡片 → 自动进入对话 → 选项卡片点选 → 最后弹出结构化结果页（重点展示资格预判+材料清单+避坑提醒）
  • 核心演示2（报修）：语音输入"空调不制冷" → 自助排查建议 → 生成报修单（展示多模态能力）
  • 核心演示3（自查）：输入绩点排名等信息 → 生成自查报告 + 量化提升建议（重点展示推理决策能力）
  • 兜底展示：问一个超纲问题 → 展示诚实兜底 + 人工联系方式（体现可靠性）
  • 技术收尾：快速展示Trae平台后台配置界面，说明基于Trae开发效率高

💡 关键技巧：演示时不要只是"打字聊天"，要突出结构化结果卡片、进度可视化、材料预检等AI独有的价值，和普通的问答机器人拉开差距。
